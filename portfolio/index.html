Jan 2026 – Jun 2026

IoT-Based Smart Parking System

  • Designed and deployed an embedded smart parking solution using STM32 Nucleo-F411RE and VL53L0X Time-of-Flight sensors to detect precise vehicle presence in individual parking slots.
  • Developed bare-metal firmware in Embedded C using STM32CubeIDE, implementing I2C communication between the MCU and ToF sensors for accurate distance measurement.
  • Implemented real-time occupancy logic — slots flagged as occupied or free based on threshold distance — with status output via UART for monitoring.
  • Optimized sensor polling rate and power consumption through interrupt-driven programming and low-power sleep modes on the STM32 platform.
  • Tested and validated system across varied vehicle heights and ambient lighting conditions, achieving consistent sub-centimeter detection accuracy.
STM32 Nucleo VL53L0X ToF STM32CubeIDE Embedded C I2C UART

2023 – 2024

Public Transport Vehicle Tracking System

  • Architected a master-slave LoRa SX1278 network where a GPS-equipped slave node on each bus transmits live coordinates to a central master node at defined intervals.
  • Integrated NEO-6M GPS modules with Arduino Uno using the TinyGPS++ library to parse NMEA sentences and extract real-time latitude/longitude data.
  • Linked a POS (Point-of-Sale) terminal to the tracking system to update seat availability counts in real time alongside the bus location feed.
  • Configured LoRa radio parameters (spreading factor, bandwidth, coding rate) to maximise range and reliability in urban environments with minimal packet loss.
  • Validated end-to-end communication range exceeding 1 km in open areas, demonstrating feasibility for city-scale public transport deployment.
LoRa SX1278 Arduino Uno NEO-6M GPS TinyGPS++ UART SPI

2024

Automatic Solar Tracking System

  • Designed a dual-axis solar tracking system using four LDR (Light Dependent Resistor) sensors arranged in quadrants to continuously detect and follow the sun's position.
  • Developed Arduino firmware that compares differential light intensity readings between opposing LDR pairs to drive SG90 servo motors for precise panel tilt and rotation adjustments.
  • Implemented a dead-band threshold in code to prevent motor jitter in near-balanced light conditions, improving mechanical longevity.
  • Measured and recorded efficiency improvements of up to 30–35% over a static flat-panel setup through angle-optimised sun tracking during daylight hours.
  • Structured the control loop with non-blocking millis()-based timing to ensure smooth, real-time tracking response without blocking the main Arduino loop.
Arduino Uno LDR Sensors SG90 Servo Arduino IDE PWM
